# AI-EOS Desktop Dashboard (Phase 1)

## Role

You are a Senior Product Designer, Senior Frontend Engineer, and UI/UX Architect.

Your task is **NOT** to build the complete AI-EOS system.

Your task is only to build a beautiful, modern desktop dashboard (frontend prototype) that represents the future AI Engineering Operating System.

Do not implement AI automation, browser automation, Antigravity integration, or backend logic.

Focus only on creating an exceptional UI and frontend architecture.

---

# Goal

Build a premium desktop dashboard that looks like software created by a top technology company.

The interface should feel clean, modern, futuristic, professional, and easy to use.

Think of products like:

* Linear
* GitHub Desktop
* Raycast
* Warp
* Cursor
* Notion
* Vercel Dashboard

Do **not** copy them. Create an original design inspired by high-end software.

---

# Technology

Use:

* React
* TypeScript
* Tailwind CSS

* Lucide Icons

Use reusable components and clean folder structure.
