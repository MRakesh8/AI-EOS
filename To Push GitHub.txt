6. RAKESH - GET SURYA'S S1 UPDATE
============================================================

If Surya has pushed new changes to S1
and Rakesh wants those changes on his laptop:

STEP 1:

git checkout S1


STEP 2:

git pull origin S1


RESULT:

GitHub → S1
     ↓
git pull origin S1
     ↓
Rakesh Laptop → S1


IMPORTANT:

This updates Rakesh's local S1 branch.


If Rakesh wants to continue his own work,
switch back to R1:

git checkout R1

============================================================
12. IMPORTANT DIFFERENCE
============================================================

git push
= Laptop → GitHub


git pull
= GitHub → Laptop


Example:

PUSH:

Rakesh Laptop
     ↓
  git push
     ↓
GitHub R1


PULL:

GitHub R1
     ↓
git pull origin R1
     ↓
Surya Laptop
